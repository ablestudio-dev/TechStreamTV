# TechStreamTV

**Personal Media Streaming for Windows**

TechStreamTV is a **portable, self-hosted personal media server** for organizing, browsing, and streaming your own media library across devices on your local network.

## Official Website

For product information, features, documentation, installation instructions, support, and updates, visit:

**https://www.techstream.tv/**

## Releases

Official TechStreamTV Server release packages are distributed through GitHub Releases.

Release-specific documentation, updates, and announcements are maintained on the official TechStreamTV website.

## Documentation

This repository does not maintain separate product documentation. The official website is the primary source for TechStreamTV documentation and information.
